# Installation

## Stable release

To install pygeog510, run this command in your terminal:

```
pip install pygeog510
```

This is the preferred method to install pygeog510, as it will always install the most recent stable release.

If you don't have [pip](https://pip.pypa.io) installed, this [Python installation guide](http://docs.python-guide.org/en/latest/starting/installation/) can guide you through the process.

## From sources

To install pygeog510 from sources, run this command in your terminal:

```
pip install git+https://github.com/lweber89/pygeog510
```
